About

Transit Pulse is a proof of concept: an AI agent pipeline that runs on its own, around the clock, on real public data, for a few dollars a month. Lausanne first, then the canton of Vaud.

Architecture

Code, aggregated data and the log live in a public GitHub repository. Each successful run adds a commit, and Cloudflare republishes the site.

Method

  • Scope: every stop whose name starts with "Lausanne" (station, metro, tl buses, boats), all operators.
  • On time: less than 3 minutes late, as for customer punctuality in Switzerland. Departure is used when measured, otherwise arrival.
  • Measured only: only times with "real" status count; estimates and forecasts are excluded. Delays above 5 hours are treated as data errors.
  • Cancellations: stops reported as cancelled in the official file.
  • No invented causes: the bulletin only mentions a disruption that appears in the official feed, without claiming it explains the figures.

Safeguards

  • Two independent checks before publication: an agent reads every sentence, code verifies every number.
  • Up to two automatic corrections; after a third refusal nothing is published and an e-mail alert is sent.
  • Spending cap of $10 a month on the API workspace, alert at $5.
  • API keys only in secrets (GitHub, Cloudflare), never in the code.
  • Comments reviewed before publication, Cloudflare Turnstile bot check, per-visitor sending limit.
  • Strict security headers (CSP, HSTS, anti-framing), admin protected by a signed session cookie.

Sources

Open data from the Swiss mobility data platform: daily file of actual times (Ist-Daten) and the disruption feed (SIRI-SX). Reuse allowed with attribution.

Author

Designed and run by Michaël Miguel, PMP-certified digital project manager, with Claude as development partner. Source code on GitHub.

Data: opentransportdata.swiss (actual times and disruptions of Swiss public transport). Figures and texts are generated automatically.

Personal proof of concept, not affiliated with SBB, tl or any other operator.
